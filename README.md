## Installation ##

This section describes how to install the plugin and get it working.

1. Upload `wp-email-posts-digest-main` directory to the `/wp-content/plugins/` directory
1. Activate the plugin `Email Posts Digest` through the 'Plugins' menu in WordPress
1. Configure under Options > Reading
